# investment-review-system
个人投资复盘系统 - AI 驱动的第二大脑投资工作流

# 投资提升之路·独立复盘系统

个人投资管理与复盘工具。

## 项目目标

建立一个手机优先的个人投资复盘系统，
支持账户管理、持仓管理、资产配置、
投资纪律检查和定期复盘。

## 技术架构

- Frontend: React + TypeScript + Vite
- Backend: Python + FastAPI
- Database: SQLite（开发阶段）

## 开发阶段

- V1.0：账户与持仓管理
- V1.1：Excel 导入与资产配置
- V1.2：月度复盘与风险检查
- V1.3：行情数据接入
- V1.4：云端部署与报告

## 数据安全

禁止提交真实账户密码、API Key
以及不应公开的个人投资数据。
